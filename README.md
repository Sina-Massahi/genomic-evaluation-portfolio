**Genomic Evaluation Portfolio**

A reproducible learning portfolio documenting my journey through genomic prediction methods, built during my PhD in Animal Breeding and Genetics.

**Purpose**

This repository documents what I learn about statistical methods in genomic evaluation — from data simulation to model fitting — with an emphasis on clarity and reproducibility over cleverness.

**Repository structure**

01-simulation/ (Synthetic data generation in Python)

02-r-implementation/ (Genomic prediction methods in R)

03-cpp-rcpp/ (C++ optimization - planned)

docs/ (Methodology notes)
